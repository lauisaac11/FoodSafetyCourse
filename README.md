# 暐凱國際課程頁 RWD 版本

目前為封閉 DEMO：只有資料夾內的第一、第二頁可以切換；其他連結與搜尋按鈕僅顯示展示提示，不會連到原站或送出資料。Facebook 外部嵌入已移除。

來源：https://www.fsi.net.tw/training.php

擷取日期：2026-10-16。保留當時第一頁的 20 筆、第二頁的 5 筆課程內容、橫幅、圖片按鈕、課程海報及原有配色。頂部導覽已依要求回滾成圖片式按鈕。

## 使用方式

解壓縮後，直接用瀏覽器開啟 `training.html` 或 `index.html`。請保留 css、js、images、upload 資料夾的相對位置。

如需放在 PHP 網站上，可使用 `training.php`，並一同上傳上述資源資料夾。

## 完整程式碼

- `training.html`：完整的可直接開啟版本，含所有 20 筆課程 HTML，沒有省略課程內容。
- `training.php`：相同內容的 PHP 副檔名版本，內文為 HTML，**不包含原網站 PHP 後端或資料庫程式**。
- `index.html`：相同內容的預設首頁版本。
- `training-page2.html`、`training-page2.php`：第二頁完整 RWD 版本；底部「第2頁／下一頁」連至此頁，「第1頁／上一頁」可返回第一頁。
- `css/training.css`：來源網站原有樣式，保留圖片式導覽及側欄。
- `css/training-rwd.css`：響應式擴充樣式，附中文註解。
- `js/training-rwd.js`：原生 JavaScript，處理 DEMO 提示、限制本機頁面切換、阻止搜尋送出，以及日期範圍驗證。
- `js/calendar.js`：來源網站日曆程式，僅供對照；本版本改用瀏覽器原生日期選擇器，因此不載入它。
- `images/`、`upload/`：下載至本機的原網站素材，包括兩頁的課程海報。
- `design-qa.md`、`reference/`：驗證紀錄及畫面。

未使用 React、Vue、Bootstrap、建置工具或 npm 套件。原始樣式與擴充樣式分開，方便查看、修改及整合。

## 響應式行為

- 1032px 以上：保留原來約 1000px 的桌面版面及左右欄。
- 761–1032px：內容寬度隨視窗調整，保留左右欄。
- 760px 以下：單欄排列，搜尋、課程在前，會員服務及側欄在後；導覽自動換行，分類為兩欄。
- 480px 以下：側欄區塊改為單欄。
- 圖片等比例縮放，表單控制項於手機使用至少 44px 高度，並保留鍵盤焦點標示與跳至內容連結。

## DEMO 功能範圍

這是課程列表第一、第二頁的完整前端 RWD 版本，課程清單是擷取當時的靜態資料，不會自動與原網站資料庫同步。

搜尋保留欄位與日期驗證，按下查詢只顯示 DEMO 提示，不發出搜尋請求，也不傳送使用者填寫的資料。

課程列表的第1頁、第2頁及上一頁／下一頁在本機兩個 RWD 頁面之間切換。第二頁是最後一頁，因此其「下一頁」維持無連結狀態。會員登入、課程詳情、報名、匯款回覆、分類、社群及其他外部連結均已改為本頁的 DEMO 提示，不會離開資料夾，也不會開新分頁。

本版本沒有串接資料庫、登入、報名或付款服務。

圖片、CSS 與 JavaScript 均由本機載入。Facebook 外部 SDK 與嵌入已移除，改為本機展示連結。來源原有的「課程成果」沒有連結目的地，本版本保留顯示。
